# 通用设备改名实施计划

2026-10-28，基于 `dd7a3a4`。本版实现通用 PnP、播放/录音端点、Classic 蓝牙改名和恢复；BLE 改名安排到下一版，当前继续提供识别和详情。

## 交付要求

- 新电脑和新型号无需导入本机验证文件。支持能力由命名接口、系统兼容性、目标当前状态决定。
- 保留预览、原值备份、写前身份与现值复核、独立回读及冲突提示。恢复要保留属性原本不存在的状态。
- PnP 使用正式属性接口；音频共用播放/录音后端；Classic 使用公开本机记录更新接口。内部接口的适配范围与实际测试结果分别记录。
- 一件设备的 PnP、音频和蓝牙命名位置分别处理。结果逐项展示，部分失败可以恢复已成功项。
- 沿用现有 TUI 导航、F3 查找、F4 提权和 F6 语言切换。补充权限状态区分、提权后的选择恢复和多个重连候选的选择。
- 实际验收记录分别说明构建/自检、系统写入与恢复、Windows 界面、退出、拔插/重连、重启和跨机器验证；没有执行的项目保留待验状态。

## 验收方式

开发测试按后端和接口契约选择代表性设备，不把测试设备清单做成产品白名单。运行时只读预检不执行试写；实际改名只在明确提交后发生。PnP 和音频身份分别使用实例 ID、完整端点 ID，不按名称或型号猜选。

软件验证通过后，对本机可定位的外设执行单设备临时命名与恢复；保留恢复材料。需要人为拔插、蓝牙实物确认、重启或第二台 Windows 机器的项目，在具备条件后执行。执行前检查当前清单，不把旧实验记作新版验收。

# 首版支持范围

目标：Windows 10 22H2 / Windows 11，x64。启动重新检测真实系统版本。当前验收环境为 Windows 11 build 22631；其他版本不会开放未经验证的内部命名路径。

| 位置 | 状态 | 证据、限制与下一步 |
| --- | --- | --- |
| 指定鼠标 PnP | 已验证，限定本机绑定 | Logitech LIGHTSPEED VID 046D / PID C547 的 Mouse 节点，SetupAPI FriendlyName。本轮真实 TUI 写入、退出独立回读、设备管理器、同口拔插、历史恢复及恢复后拔插通过；原属性缺失状态恢复。历史电脑重启证据不计为本轮重跑 |
| 指定 AB13X 录音 | 已验证，限定本机绑定 | VID 001F / PID 0B21、build 22631 的内部音频策略。本轮 TUI 写入、退出独立回读、多名称层同步、实际声音列表、同口拔插、历史恢复及恢复后拔插通过。新后端电脑重启仍待验 |
| BLE 直接缓存 / PnP 旧方案 | 已知不可靠，不开放 | VGN 旧方案出现正常重连覆盖及不完整恢复，不能作为自动回退。新内部入口本轮只验证了限定清空运行时别名及原名恢复，不是完整昵称后端 |
| BLE 完整同步后端 | 未验证，不开放 | 非空别名的编码边界、运行时与磁盘/PnP 同步顺序、完整改名往返及生命周期未验。GET 只返回解析名，不等同原始运行时别名备份。下一步见 BLE-CURRENT-RECOVERY.md |
| Classic 蓝牙 | 未验证，不开放 | 公开 BluetoothUpdateDeviceRecord 是候选；只读发现可关联条目，但没有确认且获写入授权的测试实物。须补界面、退出、重连及原始别名完整恢复 |
| 播放端点 | 未验证，不开放 | 已授权 AB13X 存在 render 端点，但 Core Audio 实读为禁用状态（2）；并非缺少实物。已实现枚举、位置和设置入口。需先由用户选择是否启用现有输出，再独立验证策略 ABI、输出影响、名称与恢复；录音证据不外推 |
| 其他 PnP / 设备 | 未验证，只读 | 枚举、筛选、搜索、识别、详情、实物查找。相同型号或类别不能自动获得写入能力 |
| 打印机 / 网络接口专用名称 | 首版范围外 | 相关 PnP 功能可只读显示，专用改名留后续 |

“已验证”仅适用于记录中的机器、具体实物、连接、系统和后端。便携包不包含本机验证配置、私有设备身份、恢复点或历史；在未配置本机已验证身份的电脑上，首版可只读使用，明确显示不可写原因。首次启动不自动建立全设备写入白名单。

写入、原生接口返回、独立回读、实际 Windows 界面、退出后保留、重连、重启分别记录。软件不会在启动、热插拔或核验时自动重新应用昵称。纯便携程序退出后没有服务或计划任务维持名称。

Windows 10 22H2 实测与本轮电脑重启、驱动/系统更新、换 USB 口、移除重配验收均为待办。本轮禁止主动重启电脑、服务及适配器。恢复后的相同生命周期事件也需单独核验。

本轮证据见 [ACCEPTANCE](ACCEPTANCE.md)。研究与后续步骤见 [NAMING-RESEARCH](NAMING-RESEARCH.md)、[NAME-PERSISTENCE](NAME-PERSISTENCE.md)。本机完整取证及恢复文件只留在被忽略的 artifacts/device-lab，不随仓库或发布包分发。

# 支持范围

目标平台：Windows 10 22H2 / Windows 11，x64。启动时检测实际系统版本。本轮已通过构建、安全检查、本机 PnP/音频/Classic 改名与恢复及代表性设备的正常重连。具体范围与未验项目见 [ACCEPTANCE](ACCEPTANCE.md)。

| 命名位置 | 后端与限制 |
| --- | --- |
| PnP 设备 | 使用设备实例的 FriendlyName，需要管理员权限。蓝牙托管节点和声音端点使用各自的路径；不可将 PnP 写入视为它们的替代方案。 |
| 播放、录音端点 | 使用声音端点的 DeviceDesc，并核对端点与 PnP 关联、名称来源及可恢复性；实际是否可写以界面结果为准。 |
| Classic 蓝牙 | 使用本机蓝牙别名，需要管理员权限。核对设备、无线电和缓存记录；关联缺失或有歧义时停止。名称保存后可能需要正常断开并重连设备，再核验；无需取消配对。 |
| BLE 蓝牙 | 当前只读，改名计划在下个版本提供。 |
| 打印机、网络接口专用名称 | 专用改名不在当前范围；可用的 PnP 命名位置按 PnP 路径处理。 |

界面根据实时设备状态、位置、权限和后端检查显示能力与原因，无需导入本机验证配置。支持某类后端不保证所有设备、驱动或 Windows 界面都能接受或保留名称。写入、独立回读、Windows 界面、退出、重连和重启应分别验收；恢复后的生命周期也需独立核验。

恢复前选择历史版本，确认当前实物并检查预览；设备身份或当前值不匹配时停止。程序启动、热插拔和核验不会自动重新应用昵称，退出后没有后台服务维持名称。

Windows 10 实机、另一台 Windows 机器、电脑重启、换接口、驱动或系统更新、移除重配仍待验收。研究材料见 [NAMING-RESEARCH](NAMING-RESEARCH.md) 和 [NAME-PERSISTENCE](NAME-PERSISTENCE.md)。

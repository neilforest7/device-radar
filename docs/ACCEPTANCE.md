Windows 11 build 22631 x64。本轮从空数据目录运行发布程序，无验证配置导入；后端按目标身份和接口条件选择，开发测试型号不参与产品准入。

| 终端交互 | AB13X 真实清单、80×24 缩放、语言切换、编辑器、预览取消、定位和提权取消的 ConPTY 冒烟通过；普通权限可进入音频编辑器。 |

| USB 录音 | 当前自定义原名完成临时改名、声音设置显示、独立回读、同口拔插保持；历史恢复及再次拔插后回到原名。 |

Classic 的 `waiting-for-reconnect` 表示名称已保存、系统列表尚待正常重连刷新，不计作已完成。结果页和历史页提供只读重新核验。混合状态可凭既有写入证据恢复；外部未知名称继续阻断。

未验：电脑重启及恢复后的重启、另一台 Windows 机器、Windows 10 实机、换接口、驱动/系统更新、移除重配。PnP 本轮没有另做设备管理器截图；HDMI/S/PDIF 没有做插拔或界面验收。音频写入前后已检查默认角色与启用状态；音量未单独比较。不能将这些项目记为通过。

本轮原始设备身份、恢复点及终端记录保存在 Git 忽略的 `artifacts/general-acceptance/`。发布包只包含公开文件，不包含这些材料。BLE 改名属于下一版。

v0.2.0 自包含 ZIP 解压到新目录后，93 项命名检查和 20 项文件检查通过，未创建 data 目录。包内 9 个文件、8 项内容哈希逐项匹配；EXE、说明、支持表、验收记录和许可证采用明确文件清单打包。

# Device Radar

免费、开源的 Windows 外设识别与改名工具。免安装，可离线使用，支持中英文。

## 使用

1. 解压便携包到可写文件夹，运行 `DeviceRadar.exe`。
2. 找到设备，选择“改名”，逐项填写名称，预览后确认写入。
3. 需要恢复时，打开“历史/恢复”，选择之前保存的版本。

`Tab` / `Shift+Tab` 切换设备列表和详情，方向键选择，`/` 搜索，`F6` 切换语言，`F5` 刷新，`Esc` 返回或退出。列表顶部按 ↑ 进入筛选，← → 选择筛选项，空格切换；详情按 PgUp/PgDn 滚动。窗口至少为 80×24。

全局工具栏提供“查找实物” (`F3`)、“管理员重开” (`F4`) 和“系统设置” (`F7`)。查找时断开再重连目标设备；若出现多个候选，请重新定位。识别结果对应当前 Windows 设备条目，不能证明实物身份。备份或移动程序时，一起保留旁边的 `data` 文件夹，其中保存着恢复记录。

## 支持范围

支持 Windows 10 22H2 / Windows 11 x64。改名后端覆盖符合条件的 PnP 设备、播放和录音端点、Classic 蓝牙；具体位置能否写入取决于设备状态、身份和权限。PnP 和 Classic 蓝牙需要管理员权限。Classic 名称保存后可能需要正常断开并重连设备，再核验；无需取消配对。BLE 改名计划在下个版本提供。本机改名、恢复及代表性设备重连已通过，重启与跨机器仍待验，详见[支持矩阵](docs/SUPPORT.md)。

## 开发

安装 .NET 10 SDK 后，在项目根目录运行：

```powershell
.\run.ps1
```

生成自包含便携包：

```powershell
.\build.ps1 -Action publish
```
